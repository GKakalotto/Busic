# 哔哩哔哩音乐

把哔哩哔哩里的视频，当成歌来听。

## 为什么做

听歌本该很简单。

现实却是：每个平台一份会员，换首歌就要换一家充值。

正版用户交了钱，内容照样被墙隔开，听起来像在给门禁续费。

这不像互联网该有的样子。

于是用哔哩哔哩开放 API，做了一款只听音频的客户端：收藏夹打开就能播，搜得到、切得动、后台也不停。

不绑一堆会员，也不逼你为同一首歌多付几遍。

## 找歌

登录后，收藏夹按卡片排开，封面、名字和数量一眼能看到。没登录也能看最近播放，听过的都会记在本地。

搜索从「我的」页弹出。搜歌名或 UP 主，结果往下滚会继续加载。搜过的词留在搜索框下面，点一下就能再搜。

## 听歌

点开就是播放页：歌名和作者在上面，封面铺满，底下是跟着声音走的频谱。底部常驻一条控制栏，海报、进度和时间、上一首、暂停、下一首都在手边。

放在后台也继续播。某一首加载失败会再试几秒，还是不行就自动换下一首，不会卡在同一首上打转。

## 账号

可以用哔哩哔哩 App 扫码登录，也可以在登录页里走官网的短信验证码。

登录状态会留在本机，下次打开不用重来。
